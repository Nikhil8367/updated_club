Get the Git

Mastering version control and open-source collaboration on GitHub.

Event Date

11 NOV 2024

Event Overview

Department of Computer Science & Engineering (Data Science), under the esteemed guidance of Dr.Y. Anuradha, Associate Head of B.Tech CSE (DS), organized a successful event, chaired by Prof. A. B. Koteswara Rao, Principal. The workshop introduced students to the fundamentals of version control, repository management, and collaborative coding workflow. This session began with introduction of the github and creating an account of github and then explained how to upload an coding files into github also explained about linux file navigation commands like cd,pwd. This session is an useful for students to gain practical experience in intilizing respositories, merging code and collaboration on projects using github it is also used to prepared them to work in team-based environments, a skill crucial for internships, technical projects, and future careers.

Key Takeaways

  • 📌 Understand the fundamentals of Git and version control
  • 📌 Learn essential Git commands and syntax
  • 📌 Create and manage repositories on GitHub
  • 📌 Work with branching and merging
